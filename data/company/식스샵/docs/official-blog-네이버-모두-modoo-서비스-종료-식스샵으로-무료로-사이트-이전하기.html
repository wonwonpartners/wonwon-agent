서비스 선택부터 이전 과정까지 하나씩 설명해 드릴게요. 1. 웹사이트 어떻게 만들면 좋을까? 웹 빌더 vs 자체 구축 사이트를 제작하는 방법은 크게 두 가지입니다. 웹 빌더를 이용하는 방법과 코드를 이용해 직접 구축하는 방법 인데요. 웹 빌더 이용 : 코딩 없이도 손쉽게 홈페이지를 만들 수 있어, 초보자도 쉽게 접근할 수 있어요. 자체 구축 : 직접 개발해 원하는 기능을 구현할 수 있지만, 개발 지식이 없으면 어렵고, 전문가에게 맡길 경우 비용이 많이 들 수 있어요. 웹 빌더 중 식스샵을 이용하면? 홈페이지를 간편하게 이전하려면 식스샵이 좋은 선택이 될 수 있어요. 식스샵은 직관적인 에디터를 제공해 혼자서도 손쉽게 웹사이트를 제작할 수 있는 게 장점 이에요. 또한, 네이버 웹마스터 도구를 지원해 네이버 검색 노출 이 가능하고 네이버 톡톡 연동 도 할 수 있어 기존 사이트의 방식 그대로 편리하게 운영이 가능해요. 만약 운영하시는 스마트스토어와의 상품/주문 연동 이 필요하다면, 식스샵 프로를 선택하면 돼요. 👉 식스샵과 식스샵 프로 비교 웹 빌더도 전문가에게 의뢰할 수 있어요! 웹 빌더를 사용하더라도 특정 기능 추가나 맞춤 디자인이 필요할 수 있어요. 식스샵에서는 공식 파트너사와 협업해, 사이트 제작부터 특정 기능 개발까지 전문가에게 직접 의뢰할 수 있는 시스템을 운영하고 있어요. 번거롭게 외부에서 업체를 찾을 필요 없이 믿을 수 있는 전문가에게 상담을 받아보세요! 👉 전문가 의뢰하기 2. 비용도 꼭 체크하세요! 홈페이지를 이전할 때 비용도 중요한 요소죠. 웹 빌더와 자체 구축 방식에 따라 비용이 달라요. 웹 빌더 : 월 구독 방식으로 운영되며, 기본적으로 SSL 인증서가 포함된 경우가 많아요. 하지만 일부 웹 빌더 솔루션은 SSL 인증서, PG 가입비 등이 별도로 들 수 있어요. 식스샵과 식스샵 프로는 월 구독료에 SSL 인증서와 PG 가입 비용이 포함되어 있어요! 자체 구축 : 도메인, 서버 호스팅, 보안 인증 비용 등을 개별적으로 지불해야 해요. 식스샵에서는 무료로 사이트를 제작할 수 있어요! 식스샵과 식스샵 프로는 기본적인 사이트 제작이 무료로 가능해요. 다만, 도메인 연결, 광고 제거, 쇼핑몰 기능 활성화 등은 유료 플랜을 이용해야 해요. 즉, 사이트를 먼저 제작한 후, 실제 운영이 필요할 때 유료 플랜을 결제하면 되므로 부담 없이 시작할 수 있어요! 👉 식스샵 무료로 시작하기 3. 네이버 모두 사이트 이전, 이렇게 하면 돼요! 1) 기존 사이트 데이터 백업 네이버 모두에서 홈페이지를 운영 중이라면, 기존 데이터를 새로운 홈페이지로 옮기는 것이 중요해요. 기본적인 데이터 이전 방법은 다음과 같아요. 💡 네이버 모두 사이트 백업 조건과 방법 백업 가능한 조건 • 공개된 홈페이지만 백업 가능(비공개 홈페이지는 '공개 처리' 후 백업 버튼이 활성화됨) • 페이지별 HTML 및 이미지 파일 다운로드 가능, PC 버전 UI 기준으로만 백업 가능 백업 방법 1. 네이버 모두 에디터 페이지 로 이동 2. ' 백업하기 ' 버튼을 클릭하면 다운로드 시작 백업이 불가능한 항목 모든 데이터를 백업할 수 있는 것은 아니며, 아래 항목들은 별도로 저장이 필요합니다. • 게시판 및 문의 신청 데이터 → '엑셀 다운로드' 기능을 이용해 직접 저장해야 합니다. • 스토어 페이지 및 방문자 통계 → 스마트스토어나 네이버 애널리틱스에서 직접 확인해야 합니다. 2) 식스샵으로 데이터 이전 식스샵에서는 데이터 이전을 무료 로 도와드려요. 아래 가이드를 보고 천천히 따라 해보세요. 👉 가이드 확인하기 3) 도메인 연결 네이버 모두에서 사용하던 개인 도메인이 있다면, 새로운 홈페이지에 연결할 수 있어요. 다만, 개인 도메인은 유료 플랜에서만 연결 가능하니 참고하세요. 도메인이 없으신 경우, 식스샵에서 직접 구매할 수도 있어요. 4) 웹사이트 디자인 이제 사이트 디자인을 시작하면 돼요! 식스샵의 고품질 템플릿과 편리한 에디터를 활용해 나에게 딱 맞는 홈페이지를 제작 해 보세요. 만약 사이트 구축이 어렵다면? 전문가에게 제작을 의뢰할 수도 있어요! 👉 제작 의뢰 문의하기 4. 지금 바로 사이트를 이전하세요! 네이버 모두 서비스 종료로 인해 홈페이지 이전이 필요한 분들에게 식스샵은 쉽고 빠른 해결책이 될 거예요. 지금 바로 식스샵을 이용해 홈페이지를 구축해 보세요! 누구나 쉽고 빠르게 만드는 나만의 웹사이트 지금 가입하고 14일 동안 모든 기능을 무료 로 사용하세요. 무료로 시작하기 식스샵팀 더 많은 쇼핑몰·홈페이지의 제작법과 운영 팁을 확인하세요 목록으로 이동하기 제휴 문의 식스샵 제작 파트너 되기 (주) 셀러허브 서울특별시 강남구 테헤란로79길 11-1 대표: 이상민 개인정보관리책임자: 이상민 사업자등록번호: 211-88-81810 통신판매업 : 2022-서울강남-04198 식스샵 고객센터 이메일: help@sixshop.com 채팅: 카카오톡 채널 (아이디 식스샵) & 채널톡 (홈페이지 우측 하단 채널톡 버튼) 채팅 상담 시간: 월~목 10:00~12:30 / 14:00~17:00 금 10:00~11:30 / 14:00~17:00 (주말, 공휴일 휴무) 이메일 상담 시간: 연중무휴 09:00~23:00 이용약관 개인정보처리방침 © (주)셀러허브 ALL RIGHTS RESERVED.

새롭게 쓰는 식스샵 ‘블록 AI’ 2025-08-22 · 디자인/제작 팁 AI 시대, 웹사이트 제작도 예외가 아닙니다. 최근 다양한 웹 빌더에서 AI 서비스를 선보이고 있지만, 대부분 ‘한 번 생성’에 집중합니다. 즉, 처음 만들어진 결과물 하나로 끝나는 경우가 많죠. 사실, AI 기술이 고도화된 오늘날에는 무언가를 만들어 내는 일 자체는 훨씬 쉬워졌습니다. 하지만 진짜 어려운 건, 내가 원하는 형태로 정확히 완성하는 것입니다. 첫 프롬프트를 잘 작성하는 능력도 중요하지만, 처음 생성된 블록을 원하는 방향으로 계속 수정하고 다듬는 경험, 바로 그것이 ‘진짜 유용한 AI’입니다. 결국, 완성이 더 중요하니까요. 그래서 식스샵은 ‘블록 AI’를 선보입니다. 블록 AI는 단순 생성에 그치지 않고, 후속 명령으로 만족할 때까지 자유롭게 수정할 수 있는 웹 제작 AI입니다. 무엇보다, 코드 기반으로 블록을 생성하기 때문에 기존 웹빌더의 제약을 뛰어넘는 자유도를 제공합니다. 블록 AI가 해결하는 문제 웹사이트 제작을 하다 보면, 기존 웹빌더로는 해결하기 어려운 순간들이 많았습니다. 식스샵 블록 AI는 바로 이런 실제 고객들의 목소리(VoC)에서 출발했습니다. 문제 1. 구현하고 싶은 기능이나 디자인 효과를 만들 수 없었다 웹빌더가 제공하는 요소에 한계가 있어, 복잡한 폼·달력, 화려한 애니메이션 같은 기능이나 다양한 디자인 효과를 구현하기 어려웠습니다. → 이제는 블록 AI를 통해 필요한 기능과 디자인을 자유롭게 만들어 쓸 수 있습니다. “웹사이트에 달력을 보여주는 기능 을 추가하고 싶다.” “입력 항목마다 하나씩 단계별로 노출되는 폼 을 추가하고 싶다.” “눈에 띄는 애니메이션 효과가 들어간 배너 를 만들고 싶다.” 문제 2. 기존 요소에서 조금만 고치고 싶은데, 불가능했다 섹션이나 블록 같은 기본 요소에서 작은 부분만 수정하거나 기능을 추가하고 싶어도, 기존 빌더에서는 불가능했습니다. → 블록 AI에서는 원하는 부분만 수정 요청하거나 기능을 추가해서, 내 필요에 맞게 바꿀 수 있습니다. “모바일 메뉴에서 상위 메뉴를 누르면 펼쳐지는 기능 이 있으면 좋겠다.” “푸터에 특정 아이콘 을 추가하고 싶다.” “이 블록만 간격과 글자 크기 를 따로 조정하고 싶은데, 기능이 없다.” 블록 AI로 만들어진 블록은 모두 코드 기반으로 생성되므로, 원하는 디자인과 기능을 끝까지 구현할 수 있는 도구입니다. 웹빌더의 한계를 없애는 ‘블록 AI’ 주요 특징 블록 AI는 사용자가 원하는 디자인 요소를 프롬프트로 입력하면 AI가 해당 요소의 코드를 자동으로 생성해 블록을 만들고, 후속 프롬프트로 자유롭게 수정 할 수 있습니다. 해외에서도 러버블(Lovable), 볼트(Bolt), 커서(Cursor) 등 ‘ 바이브 코딩(Vibe Coding) ’ 툴이 주목받고 있죠. 식스샵 블록 AI 역시 자연어 명령을 코드로 변환해 개발 생산성을 높이는 바이브 코딩 툴로, 웹사이트 제작 환경에서 곧바로 활용 가능한 블록 단위 결과물을 생성합니다. 즉, 전문 개발자가 아니더라도 누구나 직관적으로 AI를 활용해 디자인 요소를 만들 수 있으며, 기존 웹빌더에서는 불가능했던 제약 없는 블록 생성이 실제로 가능합니다. 1. 프롬프트로 즉시 생성 추천 프롬프트와 키워드 조합을 활용해 손쉽게 블록을 생성할 수 있습니다. 단순히 디자인 구성 요소만 만드는 것이 아니라, 에디터에서 바로 편집 가능한 패널까지 자동으로 생성되므로, 처음부터 완성도를 높일 수 있습니다. 2. AI로 블록 후속 수정 가능 처음 생성된 블록이 마음에 들지 않거나, 일부 요소를 바꾸고 싶을 때 후속 명령으로 즉시 수정할 수 있습니다. 텍스트, 색상, 레이아웃뿐 아니라 새로운 패널 생성도 자유롭게 가능합니다. 3. 코드 편집까지 자유롭게 블록을 세밀하게 조정하고 싶다면, ‘블록 코드 수정’ 버튼으로 블록 메이커 화면에 바로 진입해 HTML/CSS/JS 기반의 커스터마이징이 가능합니다. 4. 블록 마켓플레이스와 연동 마켓플레이스에 있는 블록을 가져와 내 스타일에 맞게 수정하거나, 나만의 블록을 만들어 공유할 수 있습니다. 기존 블록을 활용하면서도 개성 있는 페이지 제작이 가능해 제작 시간을 대폭 줄여줍니다. 5. 반복 작업 최소화 수정된 블록은 블록 메이커에 저장되어 여러 페이지에 재사용할 수 있습니다. 같은 스타일의 블록을 페이지마다 다시 만들 필요가 없어, 작업 효율이 크게 향상됩니다. 블록 AI 실제 활용법 1. 식스샵 프로 > 에디터 > 섹션 추가 > AI 블록 생성으로 이동해 주세요. 2. AI 프롬프트 창에 원하는 구성 요소를 설명해 주세요. 추천 프롬프트나 키워드를 참고하면 쉽게 작성할 수 있습니다. 예시 : 깔끔한 타이포그래피로 구성된, 미니멀하고 심플한 여성 패션 히어로 배너 3. 위 프롬프트로 생성된 블록과 함께 에디터 패널이 자동으로 만들어집니다. 4. 기존 디자인에서 수정이 필요하면 ‘AI로 블록 수정’ 버튼을 눌러 후속 명령을 내려주세요. 원본 블록은 유지되고, 수정된 블록이 원본 아래에 생성됩니다. 후속 명령 예시 : 배너 이미지를 여러 개 슬라이드로 보여주고 싶어. 5 .후속 명령을 반영한 슬라이드 배너가 완성됐습니다. 배경 이미지 리스트까지 패널에서 함께 만들어져 사용이 편리합니다. 블록 AI와 함께하는 웹사이트 제작의 미래 블록 AI는 단순히 ‘생성만 하는 AI’가 아니라, 사용자가 원하는 만큼 수정하고 완성할 수 있는 도구입니다. 식스샵 블록 AI 를 활용하면, 이제 웹 제작의 흐름은 “ 생성부터 완성까지 ” 연속적 경험으로 바뀝니다. 블록 AI로 원하는 디자인과 기능을 빠르고 정확하게 구현하고, 반복 작업도 최소화할 수 있는 웹사이트 제작의 새로운 시대가 열렸습니다. 제작 전문가라면? 식스샵 파트너로 등록하고, 블록 AI로 멋진 웹사이트를 제작해 보세요. 파트너 신청하기 누구나 쉽고 빠르게 만드는 나만의 웹사이트 지금 가입하고 14일 동안 모든 기능을 무료 로 사용하세요. 무료로 시작하기 식스샵팀 더 많은 쇼핑몰·홈페이지의 제작법과 운영 팁을 확인하세요 목록으로 이동하기 제휴 문의 식스샵 제작 파트너 되기 (주) 셀러허브 서울특별시 강남구 테헤란로79길 11-1 대표: 이상민 개인정보관리책임자: 이상민 사업자등록번호: 211-88-81810 통신판매업 : 2022-서울강남-04198 식스샵 고객센터 이메일: help@sixshop.com 채팅: 카카오톡 채널 (아이디 식스샵) & 채널톡 (홈페이지 우측 하단 채널톡 버튼) 채팅 상담 시간: 월~목 10:00~12:30 / 14:00~17:00 금 10:00~11:30 / 14:00~17:00 (주말, 공휴일 휴무) 이메일 상담 시간: 연중무휴 09:00~23:00 이용약관 개인정보처리방침 © (주)셀러허브 ALL RIGHTS RESERVED.

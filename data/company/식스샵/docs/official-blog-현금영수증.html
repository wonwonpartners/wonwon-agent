[개인소득공제]라면 휴대폰 번호를, [사업자 지출증빙]이라면 사업자 번호를 입력하게 돼요. 자동 발급 사용 안 함 : 구매자가 요청한 주문들도, 모두 수동 발급하는 설정이에요. 수동 발급 방법은 아래의 3단계로 현금 영수증 수동 발급하기 과정을 참고해 주세요. 모든 주문 : 구매자 요청 여부와 관계없이, 모두 자동 발급하는 설정이에요. 만약 구매자가 발급 요청을 하지 않은 건이라면, 국세청 지정 코드인 010-000-1234로 자진 발급되어요. 발급 요청만 : 구매자가 요청한 주문만 자동 발급하는 설정이에요. 발급 요청 정보가 없는 주문에 대해서만 수동 발급 여부를 결정할 수 있어서, 운영 효율이 매우 높아요. 외에 기능 관련 궁금한 점은 가이드로 더 자세히 살펴보실 수 있어요! 👉 가이드 확인하기 3단계로 현금 영수증 수동 발급하기 자동 발급을 사용하지 않거나, 미발급 건에 대해 고객 발급 요청이 있을 때는 식스샵 프로에서 빠르게 수동 발급할 수 있어요. [식스샵 프로 > 주문 관리 > 현금 영수증]을 클릭합니다. 현금 영수증을 발급하고자 하는 주문 건의 발급 요청 버튼을 클릭합니다. TIP! 주문 옆에 발급 종류와 구매자 식별 정보가 기재되어 있다면, 고객이 주문 시 현금 영수증 정보를 입력한 경우예요. 이 경우, 발급 처리를 꼭 해 주셔야 합니다. 3. 발급 모달 내에서 정보를 확인한 후 발급하기 버튼을 클릭하면 발급 요청이 완료됩니다. TIP! 고객이 발급 요청하지 않은 건이라면, 하단 ‘자진 발급’ 항목을 체크하여 국세청 지정 신고번호로 발급하실 수도 있습니다. 이런 것도 궁금하셨을 거예요 발급 방법과 구조를 이해했다면, 실제 운영 시 발생할 수 있는 상황과 해결 방법까지 FAQ로 확인해 보세요. ❓ 고객이 요청하지 않으면 발급하지 않아도 되나요? 원칙적으로는 고객 요청 건에 대해서만 발급 하면 됩니다. 다만, 현금 영수증 의무 발행 업종 사업자라면 건당 거래 금액 10만 원 이상일 경우 5일 이내 의무 발급해야 하며, 구매자 미요청 건은 국세청 지정 코드로(010-000-1234) 자진 발급이 필요해요. ❓ 자동 발급 시, 실제 현금 영수증 발급 처리는 언제 되나요? 발급 대상 주문이 [결제 완료] 상태로 변경될 때 발급 처리 됩니다. 국세청 홈택스 측에서 최종 발급 내역이 확인되기까지는 1-2 영업일 정도 소요될 수 있어요. ❓ 고객이 연락처(발급 정보) 입력을 잘못했을 경우, 운영자가 수정 발급할 수 있나요? 아직 미발급된 주문이라면, [식스샵 프로 > 주문 관리 > 현금 영수증]에서 해당 주문 건을 직접 발급 처리할 때 발급 모달에서 올바른 연락처를 입력해 주시면 됩니다. (상단의 수동 발급 STEP 3 중 3번 이미지 참고) 만약 이미 발급 처리가 된 주문이라면 식스샵 프로에서는 처리할 수 없어요. 토스페이먼츠 관리자 페이지나 국세청 홈택스 측에서 직접 정보 수정이 가능합니다. ❓ 주문이 취소되면, 이미 발급된 현금 영수증은 어떻게 되나요? 자동/수동 발급 무관하게, 식스샵 프로 내에서 발급된 건이라면 주문 취소 시점에 현금 영수증 발급 내역도 자동 취소 처리됩니다. 다만 식스샵 프로가 아닌, 토스페이먼츠 관리자 페이지나 국세청 홈택스에서 수기로 발급한 건이라면, 수동으로 발급 취소를 해 주셔야 해요. ❓ 세금계산서도 자동 발행이 되나요? 식스샵 프로의 자동 발급 대상은 현금 영수증 유형이에요. 세금 계산서는 국세청 홈택스 측에서 별도 발행이 필요합니다. 현금 영수증은, 평소 크게 신경 쓰지 않다가도 이슈가 생기면 곤란해질 수 있는 영역이에요. 오늘은 식스샵 프로의 현금 영수증 발급 설정과 처리 흐름을 전반적으로 짚어 보았는데요. 이제 이 내용을 바탕으로, 우리 쇼핑몰의 운영 현황을 재점검해 보세요. 세무 리스크는 줄이고, 고객 신뢰와 운영 안정성은 확 높일 수 있을 거예요! 누구나 쉽고 빠르게 만드는 나만의 웹사이트 지금 가입하고 14일 동안 모든 기능을 무료 로 사용하세요. 무료로 시작하기 식스샵팀 더 많은 쇼핑몰·홈페이지의 제작법과 운영 팁을 확인하세요 목록으로 이동하기 제휴 문의 식스샵 제작 파트너 되기 (주) 셀러허브 서울특별시 강남구 테헤란로79길 11-1 대표: 이상민 개인정보관리책임자: 이상민 사업자등록번호: 211-88-81810 통신판매업 : 2022-서울강남-04198 식스샵 고객센터 이메일: help@sixshop.com 채팅: 카카오톡 채널 (아이디 식스샵) & 채널톡 (홈페이지 우측 하단 채널톡 버튼) 채팅 상담 시간: 월~목 10:00~12:30 / 14:00~17:00 금 10:00~11:30 / 14:00~17:00 (주말, 공휴일 휴무) 이메일 상담 시간: 연중무휴 09:00~23:00 이용약관 개인정보처리방침 © (주)셀러허브 ALL RIGHTS RESERVED.
